# Парсер данных Банка России

## Описание
Проект предназначен для автоматизированного сбора данных об административных правонарушениях с сайта Банка России за период с 2025 года по март 2026 года.

Из-за ограничения RSS-ленты, предоставлявшей данные только за один месяц, был разработан Python-парсер для получения исторических данных.

## Задача
- Автоматизировать сбор данных.
- Получить исторические записи за необходимый период.
- Подготовить данные для последующего анализа.

## Используемые технологии
- Python
- Requests
- BeautifulSoup
- Pandas

## Структура проекта
```
├── data/          # Исходные и обработанные данные
├── src/           # Код парсера
├── notebooks/     # Анализ данных (при наличии)
├── requirements.txt
└── README.md
```

## Этапы работы
1. Получение HTML-страниц сайта.
2. Парсинг необходимой информации.
3. Очистка и нормализация данных.
4. Формирование итогового датасета.
5. Экспорт результатов.

## Результат
Получен структурированный датасет с данными за весь необходимый период, который использовался для подготовки аналитического отчета.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```
